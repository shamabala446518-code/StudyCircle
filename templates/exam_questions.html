Important Practice Questions

These are sample revision questions to help you prepare.

🐍 Python Programming

1. What is Python?

Explain Python and write its important features.

Answer: Python is a high-level, interpreted and general-purpose programming language. It has simple syntax and supports object-oriented programming.

2. Explain the difference between List and Tuple.

Write any four differences between List and Tuple.

Answer: A List is mutable, which means its elements can be changed. A Tuple is immutable, which means its elements cannot be changed after creation.

3. Explain if-else statements in Python.

Describe conditional statements with an example.

Answer: If-else statements are used to make decisions in a program. The if block runs when the condition is true; otherwise, the else block runs.

🗄️ Database Management System

1. What is DBMS?

Explain the meaning and advantages of DBMS.

Answer: DBMS stands for Database Management System. It is software used to create, store, manage and retrieve data from databases.

2. What is SQL?

Explain SQL and its uses.

Answer: SQL stands for Structured Query Language. It is used to create, manage and manipulate relational databases.

3. Explain Primary Key and Foreign Key.

Describe the purpose of both keys in a database.

Answer: A Primary Key uniquely identifies each record in a table. A Foreign Key connects one table with another table.

💻 Web Technology

1. What is HTML?

Explain HTML and its basic structure.

Answer: HTML stands for HyperText Markup Language. It is used to create the structure and content of web pages.

2. What is CSS?

Explain the role of CSS in web development.

Answer: CSS stands for Cascading Style Sheets. It is used to style web pages by adding colors, layouts, fonts and spacing.

3. What is JavaScript?

Explain the importance of JavaScript.

Answer: JavaScript is a programming language used to make web pages interactive and dynamic.

📊 Data Structures

1. What is a Data Structure?

Explain the importance of data structures.

Answer: A data structure is a way of organizing and storing data so that it can be accessed and modified efficiently.

2. Explain Stack and Queue.

Write the difference between Stack and Queue.

Answer: Stack follows LIFO (Last In, First Out). Queue follows FIFO (First In, First Out).

⚙️ Software Engineering

1. What is Software Engineering?

Explain the meaning of software engineering.

Answer: Software Engineering is the systematic approach to designing, developing, testing and maintaining software.

2. Explain the Waterfall Model.

Describe the phases of the Waterfall Model.

Answer: The Waterfall Model is a sequential software development model. Its phases generally include requirements, design, implementation, testing, deployment and maintenance.
